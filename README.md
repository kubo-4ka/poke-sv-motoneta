# ポケモン SV 元ネタ推測図鑑

『ポケットモンスター スカーレット・バイオレット』に出てくるポケモン・人物・地名・アイテム・技・とくせい・用語、料理・お店・ファッションの名前について、
「元ネタはたぶんこれだろう」という推測をまとめ、**一覧で読む**・**クイズで覚える**ことができる静的 Web アプリです。
正解を決めることではなく、元ネタを想像しながら**ゲームをより深く楽しむこと**を目的にしています。
日本語名と英語名の両方の由来を載せています。HTML / CSS / JavaScript だけで動き、ホーム画面に追加（インストール）できます。

## 注意

- **個人が作成した非公式のファンアプリです。** 任天堂・株式会社ポケモン・ゲームフリーク・クリーチャーズ、その他の権利者様とは一切関係ありません。
- **由来はすべて推測です。** 公式が由来を明らかにしていることはほとんどありません。説がいくつもあるものは、なるべく多く並べています（先頭が作者の考える本命）。
- **ネタバレを含みます。** 初回起動時と「設定」で、表示・出題する範囲（序盤／本編／終盤／クリア後）をチェックボックスで選べます。チェックしていない段階の情報は、一覧にもクイズの選択肢にも出ません。初回は「序盤」だけ・進化の情報は表示しない、いちばんネタバレを避けた設定で始まります。
- 対象は、追加コンテンツなしの本編で遊んでいて出会う言葉です。追加コンテンツ「ゼロの秘宝」と、ほかの作品・ポケモン HOME・配信がないと手に入らない道具や姿は収録していません。

## 収録状況

[docs/COVERAGE.md](docs/COVERAGE.md) に、カテゴリ・小分類・ネタバレ段階ごとの収録件数をまとめています。すべての言葉を網羅することを目指したものではなく、作者が気になった言葉を少しずつ増やしているベストエフォートの推測図鑑なので、割合ではなく件数だけを載せています。アプリの「収録」タブでも同じ内容を見られます。

## 機能

- **一覧**（最初に開く画面）：カテゴリごとに折りたたんで表示。アイテム・料理・技・用語・ファッションはさらに小分類ごとに折りたたむ（開閉の状態は記憶。検索中は自動で開く）。カテゴリの絞り込みも折りたたみ。並び順は既定で、ポケモンは図鑑順・技はわざマシン番号順・とくせいはパルデア図鑑で最初に持つポケモンの順など。技の威力順にも並べられる。英語の名前の横の ♪ で英語の読み上げ（設定で音声・速度・音量を選べる）。料理は食事パワー（パワー＋タイプ）で絞り込める。ポケモンはタイプのボタンで絞り込める（2 つまで。2 つ選ぶと両方のタイプを持つポケモン）。
  - 技はタイプ・分類（物理／特殊／変化）・威力・命中・PP と、「必ず当たる」「威力がとても高い大技」などのひとこと付き検索（ひらがな・カタカナ・英語・図鑑番号・わざマシン番号）、カテゴリ、並び替え（パルデア図鑑順・全国図鑑順・五十音・英語名・正答率の低い順）、「由来を隠す」
  - ポケモンはタイプ、パルデア図鑑と全国図鑑の番号、公式の分類（日本語版・英語版）、進化の系統と進化の方法、姿・フォルム付き。進化の系統の名前をタップするとそのポケモンへ移動
  - 公式ポケモンずかん・Pokédex（英語）・ポケモン Wiki・Bulbapedia へのリンク
- **クイズ**：元ネタ当て／名前当て／英語名当て／日本語名当て／英語名の元ネタ／めくりカード
  - 5・10・20・30 問・全部。間違えた問題を多めに出す、正解したら自動で次へ
  - 結果画面でふりかえり、「間違えた問題だけ」もう一度
  - キーボード：1〜4 で回答、Enter で次へ、Esc でやめる
- **収録**：収録件数、カテゴリと小分類の件数、主な内訳、ネタバレ段階 × カテゴリの件数表、推測の手ごたえ（★）の内訳
- **設定**：ネタバレ範囲、進化の系統・進化の方法の表示（ネタバレ対策）、カテゴリ、英語情報の表示、根拠の表示、テーマ、記録の消去
- **テーマ**：自動／スカーレット／バイオレット／オレンジ／グレープ／スター／カシオペア（ダーク系）
- **インストール（PWA）**：https か localhost で開くと Service Worker が動き、オフラインでも使えます

### データの書き方

```js
{ c: 'pokemon', p: 253, no: 953, ja: 'シガロコ', en: 'Rellor', sp: 0, cf: 3,
  cat: ['ころがしポケモン', 'Rolling Pokémon'],
  jo: '「コロガシ（フンコロガシ）」を逆から読んだ名前',
  eo: ['roller（転がすもの）を逆さにした綴り', '別の説…'],
  ev: '根拠・補足' }
```

- `c`：カテゴリ（`pokemon` `person` `place` `item` `move` `term` `food` `shop` `fashion`）
- `p` / `no`：パルデア図鑑／全国図鑑の番号（ポケモン）、`tm`：わざマシンの番号（技）
- `sp`：ネタバレ段階（0 序盤／1 本編／2 終盤／3 クリア後）
- `cf`：推測の確からしさ（3 ほぼ確実／2 有力／1 諸説あり）
- `jo` / `eo`：日本語名／英語名の由来。諸説あるときは配列で並べ、先頭を代表の説としてクイズに使う
- `cat`：公式の分類 [日本語版, 英語版]、`ev`：根拠・補足
- `evo`：進化の系統（段階ごとの `[名前, 進化の方法]`）、`fm`：姿・フォルム（`[日本語, 英語, 補足]`）
- `t: ['gym']` など：収録状況の集計用タグ

`data-tm.js` と `data-items.js` は 1 件を配列（`[番号, 日本語名, 英語名, 由来…]`）で書く短い形式です。各ファイルの冒頭に書き方があります。

## 更新するとき

1. データを編集したら `node tools/check.js` で整合性を確かめ、`node tools/coverage.js` を実行して `docs/COVERAGE.md` を更新します。
2. ファイルを変更したら `sw.js` の `VERSION`（例：`pmz-v12` → `pmz-v13`）を上げてください。インストール済みのアプリにも更新が届きます。
